# SHINDO — アートディレクション

> このファイルは SHINDO の視覚的な意思決定の**唯一の正**です。
> `/design-review` `/lp-section` `/ship` はここを読んでから判断します。
> 実装値は `app/globals.css` の `@theme` にあります。ここは「なぜそうしたか」を残す場所です。

出典: コンセプト＆ストーリー設計書 / HP構成書（2026-07-18・株式会社ZEN-BU）

## 1. このサイトの役割

- **プロダクト種別**: LP / コーポレートサイト（全11ページ）
- **主目的**: ① 現場メンバー（年2〜3組の移住者）② 資金パートナー（10組ほど）との出会いをつくる
- **主要読者**: 会社や事業を一区切りし次の生き方を探している人／子育て世代／余剰資金を「未来に残る構造」へ投じたい事業者
- **読者に持ち帰ってほしい一言**: 「ここは、語っているだけではない」

## 2. 方向性

**採用: 静謐なエディトリアル（和の余白 × 実証の数字）**

**理由**: コンセプトの核は「静けさと確かさ、そして遊び心」「理想より実践」。
読者はまず疑いながら読む層なので、演出で押すほど信頼が落ちる。余白と組版で語り、
数字と現場写真に語らせる構成が、この読者にいちばん効く。

**やらないこと**:
- 危機を煽るビジュアル（赤・警告・カウントダウン）。恐れではなく願いから動く、という思想と正面から衝突する。
- 完成されたユートピアの絵。「終わりのない改良のプロセス」を大切にする姿勢と矛盾する。
- スタートアップ的な高彩度・グラデーション。1000年単位の時間軸を語る声色ではない。

## 3. タイポグラフィ

書体がこのサイトの声を決めます。明朝の見出しは「静けさと確かさ」を、
ゴシックの本文は「実務的な読みやすさ」を担当する分業です。

- **見出し**: Shippori Mincho（しっぽり明朝）400 / 600
- **本文**: Zen Kaku Gothic New 400 / 500 / 700
- **和欧混植**: どちらも欧文グリフを持つため単一指定。数字は見出しで明朝、本文でゴシック。
- 日本語は字面が詰まるため、見出しは `letter-spacing` を負に、本文は行間 1.9 前後を確保する。

| トークン | サイズ / 行間 | 用途 |
|---|---|---|
| `text-display` | clamp(2rem, 5.5vw, 4rem) / 1.3 | ヒーロー見出し |
| `text-h1` | clamp(1.625rem, 3.5vw, 2.5rem) / 1.45 | ページ見出し |
| `text-h2` | clamp(1.25rem, 2.2vw, 1.625rem) / 1.55 | セクション見出し |
| `text-h3` | 1.0625rem / 1.7 | 小見出し |
| `text-lead` | clamp(1rem, 1.4vw, 1.125rem) / 2.0 | リード文 |
| `text-body` | 1rem / 1.9 | 本文 |
| `text-caption` | 0.8125rem / 1.75 | 注釈・キャプション |

- **本文の最大行長**: `max-w-prose`（38rem ≒ 全角38文字）。日本語で追える上限。

## 4. カラー

土・稲・森・雪・湧水。彩度を抑え、写真が入ったときに写真が主役になる明度設計。

| トークン | 値 | 用途 |
|---|---|---|
| `base` | `#F2EEE4` | 生成り。ページ背景 |
| `surface` | `#FAF8F3` | 雪。カード・持ち上げた面 |
| `ink` | `#23201C` | 墨。本文 |
| `ink-muted` | `#5B554B` | 注釈・補助テキスト |
| `forest` | `#1E3A2F` | 深緑。主要ボタン・帯 |
| `forest-deep` | `#132318` | 最も暗い面。フッター |
| `gold` | `#856427` | 実りの金。アクセント・強調 |
| `water` | `#3F5C66` | 湧水。図版・データ表現のみ |

制約:
- **アクセントは `gold` 1色。** 押してほしいものにだけ使う。2色目を足すと主従が消える。
- `gold` は本文の長文に使わない。キッカー・小見出し・罫・アイコンに限定する。
  生成り地で 4.71:1、雪地で 5.14:1 なので小さい文字でも AA は満たすが、
  長い本文に使うと読み疲れる。役割は「視線の起点」であって「読ませる色」ではない。
- **ダークモードは実装しない。** 生成り＝undyed という素材の比喩そのものが基調のため、
  反転すると意味が壊れる。`color-scheme: light` を明示して OS 側の自動反転も止める。

## 5. レイアウトと余白

- **最大幅**: `container-content` 72rem（1152px）／ 本文列 `container-prose` 38rem
- **ガター**: モバイル 1.25rem / タブレット以上 2rem
- **余白スケール**: 4px 基準（Tailwind 既定）＋ `spacing-section` = clamp(4rem, 9vw, 7.5rem)
- **構図**: 基本は左揃えの非対称。中央揃えはヒーローと引用のみに限定する。
  全セクション中央揃えは「誰も判断しなかった」ように見えるため。
- **角丸**: `radius-sm` 2px / `radius-md` 4px。それ以上は使わない。

## 6. モーション

- **強度: 控えめ。** 入場アニメーションは 1 セクションにつき 1 つまで。
- **標準**: 240ms / `cubic-bezier(0.2, 0, 0, 1)`
- **スクロール連動**: フェードイン（opacity + 8px の上方向）のみ。パララックスは使わない。
- `prefers-reduced-motion: reduce` で装飾的な動きを完全に停止する。

## 7. ブレークポイント

| 名称 | 幅 | 想定 |
|---|---|---|
| mobile | 375px | 実トラフィックの主戦場。ここから作る |
| tablet | 768px | 2カラムが崩れる境界 |
| desktop | 1280px | 制作時の見え方 |

## 8. 写真

**現時点で写真素材はありません。** 実装では各所に比率固定のプレースホルダを置き、
`data-photo` 属性に必要な被写体を書いてあります。差し替え時は grep して探せます。

必要な被写体（コンセプト設計書より）: 博士山、雪、水源（猫沢）、田んぼ、古民家（理空）、
手仕事、人の表情。**加工の少ない実写**。彩度を上げない。

## 9. 避けるもの（SHINDO 固有）

- **「一万年」表記を使わない。** コンセプト設計書 §8 で「1000年単位で自然を豊かに」に統一済み。
- **数値目標を前面に出さない。** 「クリアな数値目標を掲げて人を従わせない」が明示された方針。
  実績の数字（反収・標高・戸数）は載せるが、KPI 的な見せ方はしない。
- **「組織」「事業」として見せない。** コミュニティであり生き方である、という位置づけを崩さない。
- **SHINDO と ZEN-BU を混同しない。** SHINDO＝コミュニティ／生き方、ZEN-BU＝実践実験を担う法人。
